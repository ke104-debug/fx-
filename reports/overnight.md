# 夜間検証レポート (2026-11-24)

データ: USD/JPY 1時間足 2004-01〜2026-11 (約23年、142,757本。Dukascopy 2004-2024 + Yahoo 2025-)
運用の想定: 新規の取引は日本時間10時〜翌1時のみ。損切り・利確は注文で入れておき、時間外も約定。同時保有は1つ、レバレッジ最大25倍。
コスト: 往復0.8pips (スプレッド0.5 + 手動発注のずれ0.3)。各年代を100万円から複利で運用。

年代: 2004-07 / 2008-09 リーマン / 2010-12 円高・介入 / 2013-15 アベノミクス / 2016-19 低変動 / 2020-21 コロナ / 2022-26 円安・介入

## 結論

1. **今の運用の作戦 (東京レンジのロンドン抜け・レンジ逆張り・急変の反動) は、23年で見ると資金を失う。** 2024-26年にたまたま合っていただけ。
2. **23年・全年代で通用したのは「急変に付いていく (大きな流れの方向だけ)」。** 担当AIの反省から作った作戦で、前半 (2004-15) だけで設定を選んでも後半 (2016-26) で通用した。
3. **安定型 E (7年代すべてプラス)**: 1回のリスク2%で 100万→515万 (年率+7.4%、最大下落22%)。
   **損小利大型 E2**: 2%で 100万→1,789万 (年率+13.4%、最大下落29%、2倍まで約5.5年)。
4. **すべての年代で2倍以上になったシステムはなかった** (最大下落35%以内の条件で)。2倍にかかる期間は、リスク2〜3%で約5〜10年。

## 6. 注意点

- 取引は月1〜2回と少ない。「急変」が起きない月は通知がない
- 急変の直後はスプレッドが広がり、約定がずれやすい (4pipsでも利益は残る計算)
- 過去の指標の日程は、2024年より前は雇用統計のみ (FOMC は 2024-26年分のみ)
- 1時間足での検証。同じ足で損切りと利確の両方に触れた場合は損切り扱い (保守的)
- 23年で全年代プラスでも、将来も同じとは限らない。実際の運用で確かめる必要がある

1. 運用の作戦を「急変に付いていく + 指標直後の順張り」(E または E2) に切り替え、今の作戦 (東京レンジ・レンジ逆張り・急変の反動) は通知をやめて影の運用 (記録だけ) に回す
