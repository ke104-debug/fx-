# 5万円を2年で100万円 (20倍) の再検証 (2026-11-24)

きっかけ: 利用者の実績 2026-06〜11 に 5万→13万 (2.6倍)。手法は損小多利 + 指標・介入後の順張り。このペースが続けば2年で約46倍。
データ: USD/JPY 1時間足 2004-01〜2026-11。新規は日本時間10時〜翌1時、往復0.8pips、**同時保有の合計で25倍まで**。コード: `fxpred/growth.py`。

## 1. 試した方法 (入り方 × 決済 × 向き、90通り)

| 方法 | 結果 |
|---|---|
| 急変の基準を下げて回数を増やす (4倍→3倍) | 回数は年15→36回に増えるが、1回の利益が +0.30R → +0.16R に下がる |
| 介入のような大きな動き (1〜3時間で1.5円以上) は流れと逆でも付いていく | 回数わずかに増、成績はほぼ同じ (+0.29R) |
| 向きの条件なし | 1回の利益が半分以下 |
| 米国の発表時刻 (NY 8:30・10:00) の1時間足の大きな動きに付いていく | **全体でマイナス** (指標の中身を見ない形では通用しない) |
| 利益を伸ばす決済 (2ATRで建値へ、2.5ATRで追いかけ) | **最良 +0.40R** (ただし後半 2016-26 は +0.22R) |
| 利確を6ATRに広げる | +0.38R、7年代中6でプラス |
| 勝っている時に同じ量を買い増し (損切りは建値へ) | **悪化** (+0.24R)。25倍の上限で増し玉の分、元の量を減らすことになる |

## 3. なぜ届かないか (計算)

- 25倍で入ると、損切り (約1ATR) で失うのは1回あたり資金の約5%
- 過去の「急変・伸ばす」と同じ質の取引で20倍にするには約190回 (成績が過去の6割なら約260回) = **月8〜11回** 必要
- 過去23年でこの合図が出たのは**月1.2回**。回数を増やす方法 (基準を下げる・発表時刻) は、どれも1回の質が落ちて相殺された

## 4. 結論

- 過去のチャートからルールで作れる作戦では、5万→2年で100万は**届かない** (最も攻めた形で約8%、その代わり約半分が元本割れ)
- 利用者の実績のペース (半年2.6倍) が続けば数字上は届く。鍵は「良い取引を月8回以上見つけられるか」
- 次にできること: 利用者の実際の取引記録 (日時・売買・入った値・決済した値・量) をもらい、どの取引が利益を生んだかを分析 → その形を23年でルール化して確かめる
