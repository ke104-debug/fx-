# fx-predictor

米ドル絡みの主要7通貨ペア (USD/JPY, EUR/USD, GBP/USD, AUD/USD, NZD/USD, USD/CAD, USD/CHF) を
15分ごとに分析し、AI (LightGBM) が1時間後の上昇/下落を予想して、確信度の高いものだけ Discord に通知します。
**売買は行いません。** 最終判断はご自身で行ってください。

## 使い方
```bash
pip install -r requirements.txt
python -m fxpred backtest   # 過去データで予想の実力を検証
python -m fxpred run        # 最新データで予想し Discord に通知
```

| 環境変数 | 既定値 | 意味 |
|---|---|---|
| `DISCORD_WEBHOOK_URL` | なし | 通知先 Webhook (GitHub では Secrets に登録) |
| `FX_HORIZON` | 4 | 何本先 (15分足) を予想するか |
| `FX_THRESHOLD` | 0.60 | 通知する確率のしきい値 |
| `FX_COST_PIPS` | 1.0 | 検証で差し引く取引コスト |
| `FX_NOTIFY_ALL` | 0 | 1 にするとシグナルが無くても毎回一覧を通知 |

## 仕組み
- データ: Yahoo Finance の15分足 (無料・直近60日)。実行のたびに `data/` に蓄積し、履歴を伸ばします
- 特徴量: 複数期間のリターン、ボラティリティ、RSI、MACD、ボリンジャー、時間帯、ドル全体の強弱 (7ペア合成)
- モデル: 7ペアをまとめて学習する LightGBM
- 検証: ウォークフォワード (過去だけで学習し未来で採点) + 取引コスト込みの損益
- 定期実行: `.github/workflows/fx-signal.yml` が GitHub Actions で15分ごとに実行
- 同じペア・同じ方向のシグナルは予想期間中に繰り返し通知しません

## 初回検証結果 (2026-10-12〜11-23)

| 1時間後 (既定) | 52.1% | 勝率44.8%, 平均 -0.91pips |
