# ai-fx

米ドル絡みの主要7通貨ペア (USD/JPY, EUR/USD, GBP/USD, AUD/USD, NZD/USD, USD/CAD, USD/CHF) を、
**利用者が指示したときだけ** 分析し、買い (BUY) / 売り (SELL) / 様子見 (HOLD) とその理由を診断します。
常時稼働や自動売買はしません。最終判断はご自身で行ってください。

## 使い方 (Claude Code のセッションで)
「FX分析して」「ドル円どう？」のように指示すると、`.claude/skills/fx-diagnose/SKILL.md` の手順で次を行います。

1. チャート分析: 15分/1時間/4時間足のトレンド・RSI・MACD・ボリンジャー・高値安値、AIモデル (LightGBM) の確率
2. マクロ市場: 米金利・VIX・S&P500・日経平均・金・原油・ドル指数の動き
3. ニュース・経済指標の予定・金利見通しを Web で調査
4. テクニカル・ファンダメンタルズ・マクロの方向がそろった時だけ BUY/SELL、それ以外は HOLD
5. 診断を `journal/diagnoses.csv` に記録し、Discord に通知

## コマンド
```bash
pip install -r requirements.txt
python -m fxpred diagnose [USD/JPY ...]                  # 診断材料を出す (指定なしで7ペア)
python -m fxpred record USD/JPY HOLD "理由" 4            # 最終診断を記録 (4時間後に答え合わせ)
python -m fxpred evaluate                                # 過去の診断の答え合わせ
python -m fxpred backtest                                # 15分足モデルの過去検証 (直近60日)
python -m fxpred study                                   # 日足 (2004年〜) でテクニカル/マクロの効き目を検証
```

## 検証結果 (2026-11-23 時点)
| 検証 | 期間 | 正解率 |
|---|---|---|
| 日足 テクニカルのみ (1日後) | 2012〜2026年 | 50.8% |
| 日足 マクロのみ (1日後) | 同上 | 50.3% |
| 日足 テクニカル+マクロ (1日後) | 同上 | 50.5% |
| 15分足 テクニカル (1時間後) | 直近6週間 | 52.1% (コスト込み損失) |
| 15分足 テクニカル+マクロ (1時間後) | 同上 | 51.0% (コスト込み損失) |

テクニカル・マクロ指標・AIモデルのいずれも、偶然を上回る予想精度は確認できていません。
ニュースや政治情勢を加えた診断の精度は過去にさかのぼって検証できないため、
診断のたびに記録し `evaluate` で答え合わせしていきます (30件以上たまるまでは偶然の影響が大きい)。

### 検証時の注意
Yahoo の為替日足は日付が約1日ずれています。これを補正しないとマクロ指標に未来の情報が混ざり、
正解率72%のような見せかけの高精度になります (`fxpred/daily.py` 参照)。

## 売買作戦の検証 (USD/JPY 1時間足 2024-02〜2026-11, 往復コスト0.5pips)
`python -m fxpred strategies` で再現できます。シグナルは足の確定後に判断して次の足で入り、同じ足で損切りと利確の両方に届いたら損切り扱いにしています。

| 作戦 | 回数 | 勝率 | PF | 合計pips | 前半 / 後半 |
|---|---|---|---|---|---|
| A レンジ逆張り(買いのみ) | 60 | 38% | 0.87 | -216 | -379 / +163 |
| A2 レンジ逆張り(売買両方) | 230 | 32% | 0.88 | -711 | -394 / -317 |
| A3 材料待ち限定+材料前決済 | 15 | 33% | 0.86 | -60 | -59 / -1 |
| B ブレイクアウト | 231 | 43% | 0.99 | -51 | +218 / -269 |
| C 押し目買い/戻り売り | 128 | 33% | 1.12 | +372 | +828 / -456 |
| D ボリンジャー逆張り | 347 | 40% | 0.85 | -993 | -788 / -205 |

レンジ逆張りの設定48通りを試すと、合計プラスは17通り、前半・後半ともプラスは2通りでした。
「大きな流れ (20日平均の向き) と同じ方向の反発だけ取る」フィルタは、24組中 前半16組・後半17組で成績を改善しました。
今のところ、どの作戦も偶然を明確に上回るとは言えません。
