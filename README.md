# ai-fx

米ドル絡みの主要7通貨ペア (USD/JPY, EUR/USD, GBP/USD, AUD/USD, NZD/USD, USD/CAD, USD/CHF) を、
**利用者が指示したときだけ** 分析し、買い (BUY) / 売り (SELL) / 様子見 (HOLD) とその理由を診断します。
常時稼働や自動売買はしません。最終判断はご自身で行ってください。

## 使い方 (Claude Code のセッションで)
「FX分析して」「ドル円どう？」のように指示すると、`.claude/skills/fx-diagnose/SKILL.md` の手順で次を行います。

1. チャート分析: 15分/1時間/4時間足のトレンド・RSI・MACD・ボリンジャー・高値安値、AIモデル (LightGBM) の確率
2. マクロ市場: 米金利・VIX・S&P500・日経平均・金・原油・ドル指数の動き
3. ニュース・経済指標の予定・金利見通しを Web で調査
4. テクニカル・ファンダメンタルズ・マクロの方向がそろった時だけ BUY/SELL、それ以外は HOLD
5. 診断を `journal/diagnoses.csv` に記録し、Discord に通知

## コマンド
```bash
pip install -r requirements.txt
python -m fxpred diagnose [USD/JPY ...]                  # 診断材料を出す (指定なしで7ペア)
python -m fxpred record USD/JPY HOLD "理由" 4            # 最終診断を記録 (4時間後に答え合わせ)
python -m fxpred evaluate                                # 過去の診断の答え合わせ
python -m fxpred backtest                                # 15分足モデルの過去検証 (直近60日)
python -m fxpred study                                   # 日足 (2004年〜) でテクニカル/マクロの効き目を検証
```

## 検証結果 (2026-11-23 時点)
| 検証 | 期間 | 正解率 |
|---|---|---|
| 日足 テクニカルのみ (1日後) | 2012〜2026年 | 50.8% |
| 日足 マクロのみ (1日後) | 同上 | 50.3% |
| 日足 テクニカル+マクロ (1日後) | 同上 | 50.5% |
| 15分足 テクニカル (1時間後) | 直近6週間 | 52.1% (コスト込み損失) |
| 15分足 テクニカル+マクロ (1時間後) | 同上 | 51.0% (コスト込み損失) |

テクニカル・マクロ指標・AIモデルのいずれも、偶然を上回る予想精度は確認できていません。
ニュースや政治情勢を加えた診断の精度は過去にさかのぼって検証できないため、
診断のたびに記録し `evaluate` で答え合わせしていきます (30件以上たまるまでは偶然の影響が大きい)。

### 検証時の注意
Yahoo の為替日足は日付が約1日ずれています。これを補正しないとマクロ指標に未来の情報が混ざり、
正解率72%のような見せかけの高精度になります (`fxpred/daily.py` 参照)。

## 売買作戦の検証 (USD/JPY 1時間足 2024-02〜2026-11, 往復コスト0.5pips)
`python -m fxpred strategies` で再現できます。シグナルは足の確定後に判断して次の足で入り、同じ足で損切りと利確の両方に届いたら損切り扱いにしています。

| 作戦 | 回数 | 勝率 | PF | 合計pips | 前半 / 後半 |
|---|---|---|---|---|---|
| A レンジ逆張り(買いのみ) | 60 | 38% | 0.87 | -216 | -379 / +163 |
| A2 レンジ逆張り(売買両方) | 230 | 32% | 0.88 | -711 | -394 / -317 |
| A3 材料待ち限定+材料前決済 | 15 | 33% | 0.86 | -60 | -59 / -1 |
| B ブレイクアウト | 231 | 43% | 0.99 | -51 | +218 / -269 |
| C 押し目買い/戻り売り | 128 | 33% | 1.12 | +372 | +828 / -456 |
| D ボリンジャー逆張り | 347 | 40% | 0.85 | -993 | -788 / -205 |

レンジ逆張りの設定48通りを試すと、合計プラスは17通り、前半・後半ともプラスは2通りでした。
「大きな流れ (20日平均の向き) と同じ方向の反発だけ取る」フィルタは、24組中 前半16組・後半17組で成績を改善しました。
今のところ、どの作戦も偶然を明確に上回るとは言えません。

## 複数作戦の運用シミュレーション (初期資金100万円、スワップ・コスト込み)
`python -m fxpred portfolio` で再現できます。パラメータは一般的な値で固定しています。

**日足 2004〜2026年 (年率リスク10%目標)**: 12か月モメンタム +91% (年率+2.9%)、ただ買って持つ +83%、移動平均50/200 -31%、ブレイクアウト55/20日 -2%。
長期の順張りは、ドル円では「買って持つ」をほぼ上回れませんでした。

**1時間足 2024-02〜2026-11 (1回の損失=資金の1%)**
| 作戦 | 増減 | 最大下落 | 回数 | 勝率 | 損益比 |
|---|---|---|---|---|---|
| H3 東京レンジのロンドン抜け | +18% | 8% | 238 | 48% | 1.32 |
| H4 レンジ逆張り+流れフィルタ | +6% | 11% | 79 | 32% | 2.40 |
| H5 指標発表直後の順張り | +0% | 7% | 33 | 33% | 2.04 |
| H2 押し目買い/戻り売り | -9% | 29% | 149 | 27% | 2.49 |
| H1 ブレイクアウト(5日高安値) | -18% | 41% | 175 | 22% | 3.08 |
| 基準: 買って持つ (1倍) | +13% | 13% | - | - | - |

H3 は設定を81通り変えても71通りでプラス (前半・後半ともプラスは56通り)、同じ場面でランダムな方向に入った場合 (30回) を29回上回りました。
ただし2024年は-3%で、検証期間は2.8年だけです。

## リスクの大きさと増え方 (`python -m fxpred.risk_study`)
H3 の1回あたりの期待値は約 +0.075R (損切り幅の7.5%) と小さく、1回のリスクを上げると増え方は頭打ちになります。
| 1回のリスク | 2.8年の結果 | 最大下落 | 半年で+150%以上の確率 | 半年で資金半減以下の確率 |
|---|---|---|---|---|
| 1% | +18% | 8% | 0% | 0% |
| 3% | +54% | 24% | 0% | 0% |
| 5% | +66% | 37% | 0.3% | 0.4% |
| 10% | +60% | 59% | 3.3% | 4.3% |
H3+H4+H5 を同時に使い3%なら +71% (最大下落40%)。ロンドンレンジのNY抜け (H6) は -11% で不採用。

## 急落・急騰の反動を取る作戦 (`python -m fxpred.shock`)
24時間で2円以上動いた後、下げ止まり (上げ止まり) を確認してから、下げ幅の40%戻りを狙う。損切りは急落の安値の0.2円下。
**大きな流れ (20日平均の向き) の方向へ戻る場合だけ**取る (`shock.trend_aligned`)。
- 2024-02〜2026-11: 54回、勝率67%、1回平均 +0.35R、2024/2025/2026年とも +0.23〜+0.44R
- 1回のリスク5%: 100万円 → 239万円 (最大下落17%)。8%: 408万円 (最大下落22%)
- 急落直後にすぐ買う (下げ止まりを待たない) と成績は悪化
- 注意: 流れのフィルタは年別の結果を見た後に加えたもので、2.8年・54回だけの検証。長期データでの確認が必要

## AI_FX の3つの強み (`fxpred/edge.py`、追加料金なし)
- **急騰・急落検知**: 1時間/3時間/24時間の動きが普段 (直近20日) の何倍かを計算。4倍以上または24時間で2円以上で「急変」(時間外でも通知)、3倍以上で「注意」
- **高確度局面検知**: 時間足の方向・重要な価格帯・AIモデル・市場心理 (VIX)・相場状態・検証済み作戦のシグナル の6条件のうち、5つ以上一致で「高確度」
- **ノートレード判定**: 重要指標の6時間前、急変の最中、週末前、祝日の薄商い、時間足の方向の食い違い、値幅が小さすぎる時は取引を推奨しない
通知は「現在の相場 / 判定 / 信頼度 / 判断の理由 / そろっていない条件 / 売買戦略 / 警戒事項」の形式。数量の目安は載せない。

## 担当AI・まとめ役・毎日の予想と自己改善
- `fxpred/specialists.py`: 急変担当 (無料ニュースの見出しから原因を判定)、レンジ担当 (何度も反発した下値・上値、行き過ぎ)、トレンド担当 (続いている時間、勢いの衰え、転換のサイン)、まとめ役 (相場状態で主担当を決め、主担当の意見を2倍で合計)
- `python -m fxpred morning`: 毎朝10時 (日本時間) に、昨日の予想の答え合わせ → 自己改善 (担当ごとの重み・予想値幅の補正を `journal/learning.json` に保存) → 今日の予想を Discord に送る
- 監視の通知は、信頼度「中」以上で、担当AIの見立てと逆向きでない時だけ送る (急変の反動は除く)。送ったシグナルは `journal/signals.csv` に記録
- 2026-08〜11 の95日をさかのぼって試すと、値幅の的中は前半33%→後半62%に改善。方向の正解率は39%で、当たらない担当の重みが自動で下がり「中立」が増えた

## 自動運用 (GitHub Actions, `.github/workflows/fx-auto.yml`)
- 毎時5分 (UTC 日〜金) に `python -m fxpred auto` を実行。日本時間10時台の最初の1回は朝の予想・振り返りも行い、`journal/` をリポジトリに保存
- 必要な設定: リポジトリの Settings → Secrets and variables → Actions → New repository secret で `DISCORD_WEBHOOK_URL`
- 通知時間は `config/notify.json` (通常 10:00〜25:00、急変は時間外でも)
- 手動実行: Actions タブ → 「AI_FX 自動運用」→ Run workflow (朝の予想も試すならチェックを入れる)

## 週次・月次の見直し (`fxpred/periodic.py`)
- 毎週土曜10時 (日本時間): 1週間の「送ったシグナル」「見送ったシグナル (もし入っていたら)」「信頼度の帯ごとの成績」「毎朝の予想の当たり」を集計して Discord に送る
- 毎月最初の土曜10時: 同じ内容を1か月分で集計し、条件ごとの配点も見直す
- 調整は件数が十分ある時だけ小さく: 週次は通知の基準点を±5 (8回以上、範囲45〜75%)、月次は条件の配点を±5 (20回以上)。履歴は `journal/learning.json`
- 手動: `python -m fxpred auto --weekly` (月次も: `--weekly --monthly`)

## 5分監視とデータ取得 (公開リポジトリのため GitHub Actions は無料)
- `.github/workflows/fx-quick.yml`: 5分ごとに `python -m fxpred.quick`。急変は時間外でも通知、チャンスの候補は AI の詳しい分析を経て通知
- `.github/workflows/duka-download.yml`: 手動実行。Dukascopy の1時間足を最大5時間かけて取得し `data-duka` ブランチに保存 (何度でも続きから)
- 記録 (`journal/`) は git に、監視の状態 (`state/`) は Actions のキャッシュに保存

## 5分足での反発確認 (5分監視に採用)
下値・上値に近づいただけでは入らず、5分足が陽線 (上値なら陰線) で戻したのを確認してから AI の詳しい分析に回す (`fxpred/quick.py` の `confirmed`)。
直近12週 (Yahoo 5分足、2026-09〜11) の検証: すぐ入る 142回 勝率31% -171pips → 反発確認後 128回 勝率31% +108pips。

## 決済の通知 (`fxpred/positions.py`)
通知した売買を `journal/positions.json` に「保有中」として記録し、5分監視で確認。利確・損切り・保有期限・含み益 (利確まで半分で建値への移動を提案) を、時間にかかわらず通知。決済結果は `journal/closed.csv`。

## 人の操作の遅れを入れたテスト (`fxpred/replay.py` の `delayed`)
- 毎時の分析の通知 (2024-03〜、1時間足): 遅れ0時間 平均+10.5pips / 1時間 +9.5 / 2時間 +10.3 → 遅れに強い
- 5分監視の通知 (直近60日): 合計3〜33分の遅れでも平均+3〜5pips。決済まで手動で30分遅れると +4.4 → +1.9 に低下
- 推奨: エントリーと同時に損切り・利確を注文 (IFD-OCO) で入れておく
